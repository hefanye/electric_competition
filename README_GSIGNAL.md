# STM32F407 G题信号测量分析装置 - 信号采集与显示系统

## 一、项目概述

本项目是基于 STM32F407VGT6 微控制器与 AD9226 高速模数转换器实现的"G题信号测量分析装置"。系统集成了高速并行数据采集、8192 点 FFT 频谱分析、时域/频域参数测量（峰峰值 Upp、有效值 Urms、基波频率 f1）、串口屏实时波形与频谱显示、以及 PC 串口旁路数据输出等完整功能，适用于电赛 G 题类信号分析场景。

### 核心功能

1. **AD9226 高速采集**：12 位并行 ADC，采样率高达 4MHz，通过 TIM1 PWM 触发 + DMA 方式实现连续无缝采集。
2. **8192 点 FFT 分析**：基 2 蝶形运算，配合汉宁窗抑制频谱泄漏，输出幅度谱用于基波频率搜索与谐波分析。
3. **时域参数测量**：Upp（峰峰值）、Urms（有效值）、直流偏置、波形因数等统计量。
4. **频域参数测量**：f1（基波频率）、谐波幅度、频谱信噪比估计。
5. **串口屏显示**：UART4 串口屏实时显示 200 点波形曲线、200 点频谱曲线及测量数值。
6. **PC 串口旁路输出**：USART1 同步以 115200 波特率向 PC 输出原始采集数据与测量结果，便于上位机调试与记录。

## 二、硬件连接说明

### 2.1 AD9226 模数转换器

| AD9226 引脚 | STM32F407 引脚 | 说明 |
|-------------|----------------|------|
| ACLK（采样时钟） | PA8（TIM1_CH1 PWM 输出） | 由 TIM1 产生 4MHz 方波作为 ADC 采样时钟 |
| AD0 ~ AD11（12 位数据） | PE0 ~ PE11 | 12 位并行数据总线，GPIO 输入模式 |
| OTR（溢出标志） | 可选 | 模拟输入超出量程指示 |

### 2.2 串口分配

| 外设 | 引脚 | 用途 | 波特率 |
|------|------|------|--------|
| USART1 | PA9 (TX) / PA10 (RX) | PC 串口调试与旁路数据输出 | 115200 |
| UART4 | PC10 (TX) / PC11 (RX) | 串口屏（陶晶驰 TJC/USART GUI）通信 | 由屏幕配置 |
| UART5 | PC12 (TX) / PD2 (RX) | DDS 模块（AD9833/AD9850 等）控制 | 9600 |

### 2.3 电源与时钟

- 主控晶振：HSE 8MHz，通过 PLL 倍频至 168MHz 系统时钟。
- APB2 定时器时钟：168MHz，APB1 定时器时钟：84MHz。
- AD9226 模拟供电 5V，数字供电 3.3V，模拟输入范围 0~5V（单极性）。

## 三、软件架构说明

### 3.1 整体数据流

```
AD9226 12位并行数据
        |
        v
   GPIO PE0~PE11 读取
        |
        v
   TIM1 PWM 4MHz 触发 --> DMA 双缓冲采集 8192 点
        |
        v
   analyse_frame() 数据处理
     |-- 去直流偏置
     |-- 加汉宁窗
     |-- 8192点 FFT
     |-- 频谱幅度计算
     |-- 峰峰值/有效值/基波频率测量
        |
        v
   UI_Controller 分发
     |-- 更新屏幕变量（数值）
     |-- 推送波形曲线（200点）
     |-- 推送频谱曲线（200点）
        |
        v
   Screen_Protocol 发送
     |-- UART4 串口屏协议帧
     |-- USART1 PC串口旁路输出
```

### 3.2 模块分层

1. **驱动层**
   - `ad9226_debug_nogain.c/h`：AD9226 GPIO 初始化、TIM1 PWM 时钟生成、DMA 双缓冲采集、半传输/完成中断回调。
   - `tim.c`：TIM1 PWM 配置（4MHz 采样时钟）、定时器中断。
   - `dma.c`：DMA2 数据流配置，外设到内存（GPIO IDR → 缓冲区）。
   - `usart.c`：USART1/UART4/UART5 初始化及 DMA 发送。

2. **算法层**（`User/algorithm/`）
   - `signal_process/fft.c`：8192 点基 2 FFT 蝶形运算（定点/浮点）。
   - `signal_process/window_functions.c`：汉宁窗、汉明窗、布莱克曼窗系数生成。
   - `signal_process/spectrum_analysis.c`：幅度谱计算、峰值搜索、频率插值。
   - `measure/statistics.c`：均值、方差、峰峰值、有效值计算。
   - `measure/amplitude_measurement.c`：基于时域的 Upp/Urms 测量。
   - `measure/frequency_measurement.c`：基于频谱峰值的基波频率 f1 估计。

3. **应用层**
   - `g_signal_measurement.c/h`：G 题测量核心调度，`analyse_frame()` 统一处理采集帧，调用算法库完成测量。
   - `g_signal_pc_debug.c/h`：PC 串口旁路输出，格式化测量结果与原始数据。
   - `screen_protocol.c/h`：串口屏 TJC 协议封装，变量赋值、曲线推送。
   - `dds_at.c/h`、`dds_ui.c/h`：DDS 信号源控制（频率/幅度/波形设置）。

4. **UI 层**（`User/UI/`）
   - `ui_controller.c/h`：UI 事件分发，接收串口屏触摸指令，触发采集模式切换。
   - `ui_display.c/h`：数值显示更新（Upp、Urms、f1 等文本控件）。
   - `ui_plot.c/h`：波形/频谱曲线绘制，将 8192 点降采样为 200 点推送屏幕。
   - `ui_types.h`、`ui_hmi_map.h`、`ui_defines.h`：UI 数据结构定义与屏幕控件 ID 映射。

### 3.3 关键中断设计

- **DMA 半传输中断（HT）**：前 4096 点采集完成，可对前半缓冲区进行处理。
- **DMA 完成中断（TC）**：8192 点全部采集完成，触发 `analyse_frame()` 进行 FFT 与测量。
- 采用双缓冲思想，避免采集与处理竞争同一内存区域。

## 四、关键参数与计算

### 4.1 采样系统参数

| 参数 | 数值 | 计算说明 |
|------|------|----------|
| 采样率 fs | 4 MHz | TIM1 PWM 输出 4MHz 方波驱动 AD9226 ACLK |
| 采样点数 N | 8192 (2^13) | 满足基 2 FFT 要求 |
| 频率分辨率 Δf | 488 Hz | Δf = fs / N = 4000000 / 8192 ≈ 488.28 Hz |
| 频率分析范围 | 0 ~ 2 MHz | 奈奎斯特频率 fs / 2 |
| 时域窗口长度 | 2.048 ms | T = N / fs = 8192 / 4MHz = 2.048 ms |

### 4.2 测量算法说明

**峰峰值 Upp 计算**：
```
Upp = (max(samples) - min(samples)) × V_ref / 4095
```
其中 V_ref = 5.0V（AD9226 模拟输入量程），12 位分辨率 4095。

**有效值 Urms 计算**：
```
Urms = sqrt( (1/N) × Σ(x[i]² - x_dc²) )
```
先去直流偏置 x_dc = mean(samples)，再计算交流分量的均方根值。

**基波频率 f1 估计**：
1. 对 8192 点加汉宁窗后做 FFT。
2. 在有效频段范围内搜索幅度谱最大峰值索引 k。
3. 采用抛物线插值提高频率分辨率：
```
f1 = (k + δ) × Δf
δ = 0.5 × (X[k-1] - X[k+1]) / (X[k-1] - 2×X[k] + X[k+1])
```
其中 X[k] 为第 k 根谱线幅度，δ 为插值偏移量。

### 4.3 显示参数

| 参数 | 数值 | 说明 |
|------|------|------|
| 波形显示点数 | 200 | 从 8192 点等间隔降采样 |
| 频谱显示点数 | 200 | 取有效频段等间隔抽取 |
| 屏幕刷新率 | 约 50 Hz | 每 20ms 更新一帧 |

## 六、使用说明

### 6.1 硬件准备

1. AD9226 模块按上文引脚表连接至 STM32F407。
2. 串口屏通过 UART4 连接（注意 TX/RX 交叉）。
3. PC 通过 USB 转串口模块连接 USART1（PA9/PA10），波特率 115200。
4. DDS 模块连接 UART5（PC12/PD2），用于产生待测信号（可选）。

### 6.2 操作流程

1. 上电后系统自动初始化，串口屏显示主界面。
2. 在串口屏上点击相应按钮触发采集模式：
   - **1 周期模式**：采集并显示 1 个信号周期的波形。
   - **3 周期模式**：采集并显示 3 个信号周期的波形。
   - **频谱模式**：采集并显示 8192 点 FFT 频谱曲线。
3. 采集完成后，串口屏自动更新波形/频谱曲线及测量数值（Upp、Urms、f1）。
4. 同时，PC 串口以 115200 波特率同步输出测量结果与原始数据帧。

### 6.3 PC 串口输出格式示例

#### 测量结果帧
```
[G-MEAS] Upp=2.456V Urms=0.872V f1=10015Hz DC=2.498V N=8192
```

#### 波形数据帧（前若干点示例）
```
[WAVE] 200
0x0800 0x0805 0x0810 0x0820 0x0838 0x0856 0x087A 0x08A0 ...
[SPECTRUM] 200
0x0012 0x0018 0x0025 0x0040 0x0080 0x0140 0x0280 0x0500 ...
```

#### 原始数据帧（旁路输出，便于上位机分析）
```
[RAW] idx=0..8191
2048 2052 2060 2075 2098 2128 2164 2208 2258 2312 ...
```

字段说明：
- `Upp`：峰峰值（V）
- `Urms`：交流有效值（V）
- `f1`：基波频率（Hz）
- `DC`：直流偏置（V）
- `N`：采样点数
- `[WAVE]`：200 点波形数据（十六进制原始 ADC 值）
- `[SPECTRUM]`：200 点频谱幅度（十六进制）
- `[RAW]`：8192 点原始数据（十进制 ADC 值，分多行）

## 八、问题分析与设计要点

### 8.1 高速采集的实时性保障

AD9226 在 4MHz 采样率下每秒产生 4M×12bit 数据，若采用 CPU 轮询读取将占用全部带宽。本系统采用 **TIM1 PWM 硬件触发 + DMA 自动搬运** 方案：TIM1 CH1 输出 4MHz 方波驱动 AD9226 ACLK，每次时钟上升沿 ADC 完成一次转换，同时通过 GPIO IDR 寄存器由 DMA2 自动搬至内存缓冲区，全程零 CPU 开销。

### 8.2 FFT 频谱泄漏抑制

由于非整周期截断，直接 FFT 会产生频谱泄漏。本系统在 FFT 前施加**汉宁窗**（Hanning Window），主瓣宽度虽增至 4 根谱线，但旁瓣衰减达 -31.5dB，有效抑制远端泄漏。代价是幅度精度下降约 50%，需在后续幅度计算中乘以恢复系数 2.0。

### 8.3 频率分辨率与插值

8192 点 FFT 在 4MHz 采样率下频率分辨率为 488Hz，对于 10kHz 信号只能定位到约 9766Hz 或 10254Hz。为提高精度，采用**抛物线插值**：利用峰值谱线及其左右两根谱线的幅度，拟合抛物线顶点偏移量 δ，实现亚谱线精度。实测 10kHz 信号频率估计误差可控制在 ±20Hz 以内。

### 8.4 双缓冲避免数据竞争

DMA 采集与 CPU 处理若操作同一缓冲区会导致数据撕裂。本系统利用 DMA 半传输中断（HT）和完成中断（TC）实现乒乓缓冲：HT 触发时处理前 4096 点，TC 触发时处理后 4096 点，采集与处理交替进行，保证数据完整性。
