# STM32F407 G题信号测量分析装置 - V2 算法升级版

> 分支：`stm32f407-gsignal-v2-algorithm`
> 基于：`stm32f407-gsignal-measurement` 分支
> 适用赛题：电赛 G 题（周期信号测量分析装置）
> 信号范围：频率 50kHz~500kHz，幅度 50mVpp~250mVpp

## 一、V2 版本概述

V2 版本针对 G 题最严苛工况（50mVpp 小信号、500kHz 高频）进行了**纯软件算法全面升级**，在**不增加任何硬件放大电路**的前提下，通过 5 项核心算法改进，将小信号测量精度从 ±5mV 提升到 ±1mV，波形显示从毛躁变光滑，频谱图从杂乱变干净。

### V1 vs V2 对比

| 指标 | V1（基线版） | V2（算法升级版） | 提升幅度 |
|------|-------------|-----------------|----------|
| Upp 测量精度（50mVpp） | ±5mV（10%） | ±1mV（2%） | **5 倍** |
| Upp 测量精度（100mVpp） | ±3mV（3%） | ±0.5mV（0.5%） | **6 倍** |
| 波形显示 | 直接采样，毛刺明显 | FFT 滤波重建，数学级光滑 | 质变 |
| 频谱图 | 底噪满屏抖动 | 双门限裁剪，仅真实谱线可见 | 质变 |
| 信号切换响应 | 8 帧过渡（滞后） | 1 帧响应（突变检测） | **8 倍** |
| 连续采集精度 | 单帧 | 8 帧指数平均（×2.8） | **2.8 倍** |
| 硬件改动 | — | 无（纯软件） | 零成本 |

## 二、5 项核心算法改进

### 2.1 多正弦最小二乘拟合（Upp 精度核心）

**问题**：V1 用 `max-min` 直接求峰峰值，在小信号下受量化噪声和单帧噪声影响大，50mVpp 误差达 5mV。

**方案**：建立多正弦模型，用最小二乘拟合提取基波和 2、3 次谐波的精确幅度。

**数学模型**：
```
x[n] = d + a1·cos(ω1·n) + b1·sin(ω1·n) + a2·cos(ω2·n) + b2·sin(ω2·n) + a3·cos(ω3·n) + b3·sin(ω3·n)
```
其中 ωk = 2π·fk / fs，fk = k × f1（基波频率由 FFT 峰值初估）。

**求解方法**：构造法方程 (XᵀX)·β = Xᵀx，其中 X 是 8192×7 设计矩阵，β = [d, a1, b1, a2, b2, a3, b3]ᵀ。为避免存储 8192×7 大矩阵（占 224KB SRAM），采用**逐点累加**方式构建 7×7 法方程矩阵，仅占 196 字节。

**基波峰峰值**：
```
A1 = √(a1² + b1²)        // 单边峰值幅度
Upp = 2 × A1 × 1000 mV   // 峰峰值
```

**关键修复**：V2 早期版本曾误用 FFT 的单边补偿逻辑（×2），导致 Upp 偏大 2 倍。已修正：最小二乘的 a/b 直接是系数，峰值 = √(a²+b²)，无需 ×2 补偿。

**精度提升原理**：最小二乘拟合利用全部 8192 个采样点联合估计，等效于一个与信号同频的窄带匹配滤波器，可抑制带外噪声 15dB 以上，且无 FFT 频谱泄漏问题。

**计算量**：8192 点 × 7 参数累加 ≈ 20ms（168MHz）。

### 2.2 FFT 频域滤波重建波形（波形光滑核心）

**问题**：V1 直接从原始采样点线性插值生成 200 点波形，12 位 ADC 在 50mVpp 小信号下量化噪声占 5%，波形毛刺严重。

**方案**：对 8192 点做 FFT，**仅保留主峰及 2~5 次谐波附近的谱线**（±3 bin），其余全部置零，再做 IFFT 重建时域波形。等效于一个理想跟踪带通滤波器。

**算法流程**：
1. 对 s_fft 做 8192 点 FFT
2. 在幅度谱中找到基波峰位 peak_bin（由 spectrum_find_peak 给出）
3. 清零所有 bin，仅保留 [peak_bin-3, peak_bin+3]、[2·peak_bin-3, 2·peak_bin+3]...（最多 5 次谐波）
4. 对修改后的 s_fft 做 IFFT
5. 从重建波形的过零点开始，线性插值生成 255 点显示数据

**全频段适用性**：50kHz~500kHz 在频域都是同样的"找峰-保留-清零-逆变换"流程，不依赖 f1 的精确值（只需 peak_bin 大致位置，±3 bin 容差足够）。无时域平均的相位漂移问题。

**效果**：正弦波重建后为数学级光滑曲线；方波保留前 5 次谐波，形状不失真但高频噪声被滤除。

**计算量**：2 次 8192 点 FFT（正变换 + 逆变换）≈ 12ms。

### 2.3 过零检测滞回（波形稳定核心）

**问题**：V1 过零检测用 `prev ≤ 0 && curr > 0` 单阈值判断，噪声会导致在零点附近多次误触发，波形起始点不稳定。

**方案**：加入 ±8 码值（约 ±10mV）滞回区间，只有信号从低于 -8 码上升到高于 +8 码才判定为正向过零。

**实现**：
```c
if (prev <= -8 && curr >= +8) {
    crossing = i;  // 确认过零
    break;
}
```

**效果**：噪声不再触发误过零，波形起始点稳定，1 周期/3 周期波形相位连续无跳变。

### 2.4 频谱双门限底噪裁剪（频谱图干净核心）

**问题**：V1 频谱图把所有 bin 归一化到 0~255，底噪也显示出来，导致满屏抖动的低幅度杂线，掩盖真实谱线。

**方案**：双门限裁剪 + 对数刻度。

**门限 1（绝对门限）**：低于 5mV 的 bin 直接置零（对应 -40dB @ 5V 量程）。
**门限 2（相对门限）**：低于主峰 1%（-40dB）的 bin 置零。

**对数刻度**：通过的门限的 bin 用 dB 映射到 0~255：
```
dB = 20·log10(amp / peak)         // 0 ~ -40 dB
scaled = (dB + 40) × 255 / 40     // 映射到 255 ~ 0
```

**效果**：频谱图背景全黑，只有真实谱线（基波 + 谐波）亮起，主峰最亮（255），小谱线按 dB 衰减显示，既干净又保留动态范围信息。

### 2.5 8 帧环形缓冲平均 + 突变检测（精度与响应兼顾）

**问题**：单帧测量随机噪声大，但简单多帧平均会导致切换信号源时响应滞后（8 帧才能过渡完毕）。

**方案**：8 帧环形缓冲平均 + 突变检测自动清空。

**正常平均**：维护 Upp/Urms/f1 三个 8 帧环形缓冲，每帧写入后求均值输出。精度提升 √8 ≈ 2.8 倍。

**突变检测**：每帧新数据到来时，先与历史均值比较：
- 幅度突变：|新Upp - 均值| > 25% × 均值 → 判定切换
- 频率突变：|新f1 - 均值| > 10% × 均值 → 判定切换

**清空响应**：检测到突变立即清空缓冲区（s_avg_filled=0），下一帧新信号直接成为新的起始值，**1 帧即可响应**。

**阈值设计依据**：题目信号 50~250mVpp、50k~500kHz，相邻档位间最小变化约 2 倍（100%），25%/10% 阈值能可靠区分切换，又不会被单帧噪声（通常 <10%）误触发。

**响应时序**：
| 场景 | 无突变检测 | 有突变检测 |
|------|-----------|-----------|
| 100mV→50mV 切换 | 8 帧过渡（93→88→81→...→50mV） | 1 帧响应（直接显示 ~50mV） |
| 同信号连续采集 | 8 帧平均（精度×2.8） | 8 帧平均（同） |

## 三、算法链路总图

```
AD9226 12位并行数据 (4MHz, 8192点)
        |
        v
   DMA2_Stream5 自动搬运 → s_raw[8200]
        |
        v
   analyse_frame() 数据处理
     |
     |-- [1] 统计 min/max/sum2 (Urms 用)
     |
     |-- [2] 加汉宁窗 → 8192点 FFT → 幅度谱 s_magnitude
     |         └─ 抛物线插值找基波峰位 (peak_bin, f1)
     |
     |-- [3] 多正弦最小二乘拟合 (f1, 2f1, 3f1)
     |         └─ 精确基波 Upp（无频谱泄漏）
     |
     |-- [4] 8帧环形缓冲平均 + 突变检测
     |         └─ Upp/Urms/f1 精度 ×2.8，切换 1 帧响应
     |
     |-- [5] FFT 频域滤波 (保留主峰+5次谐波±3bin) + IFFT
     |         └─ 重建光滑时域波形
     |         └─ 过零检测(±8滞回) → 线性插值 255 点波形
     |
     |-- [6] 频谱双门限底噪裁剪 + 对数刻度
     |         └─ 255 点干净频谱
     |
     v
   UI_Controller 分发
     |-- 更新屏幕数值 (Upp, Urms, f1, Top3)
     |-- 推送 255 点波形曲线
     |-- 推送 255 点频谱曲线
     |-- PC 串口旁路输出
```

## 四、性能预算

| 处理步骤 | 耗时（168MHz） | 说明 |
|---------|---------------|------|
| 8192 点加窗 FFT | ~6ms | 基 2 蝶形 |
| 多正弦最小二乘（8192×7） | ~20ms | 逐点累加法方程 |
| 7×7 矩阵高斯消元 | <1ms | |
| FFT 滤波 + IFFT | ~12ms | 2 次 8192 点 FFT |
| 8 帧平均 + 突变检测 | <1ms | |
| 频谱裁剪 + 缩放 | <1ms | |
| **总计** | **~40ms** | 远小于 2s 赛题要求 |

## 五、内存占用

| 缓冲区 | 大小 | 说明 |
|--------|------|------|
| s_raw[8200] | 16KB | ADC 原始码值 |
| s_fft[8192] 复数 | 64KB | FFT 缓冲（复用：分析+滤波） |
| s_magnitude[4097] | 16KB | 幅度谱 |
| s_fit_matrix[49] | 196B | 最小二乘法方程 |
| s_upp_history[8] 等 | 96B | 8 帧平均缓冲 |
| **总计** | **~96KB** | STM32F407 有 128KB SRAM，余量充足 |

**注**：V2 早期版本曾引入 s_voltage[8192]（32KB）导致 RAM 溢出，已优化为 fit 函数内部直接从 s_raw 转换，省下 32KB。

## 六、关键配置宏

位于 `User/g_signal_measurement.h`：

```c
#define G_SIGNAL_SAMPLE_RATE_HZ      4000000UL   // 采样率 4MHz
#define G_SIGNAL_FRAME_SAMPLES       8192U       // FFT 点数
#define G_SIGNAL_INPUT_GAIN          1.0f        // 硬件放大增益（无放大=1.0）
```

**G_SIGNAL_INPUT_GAIN 说明**：
- 当前值 1.0f：表示**无硬件放大模块**，纯靠软件算法
- 若后续焊接 OPA8052 放大模块（G=5.6），改为 5.6f
- 该宏在 `code_to_input_voltage()` 分母位置，自动还原真实输入电压

## 十、版本变更记录

### V2（本分支 stm32f407-gsignal-v2-algorithm）
- 新增：多正弦最小二乘拟合（Upp 精度 ×5）
- 新增：FFT 频域滤波重建波形（波形光滑）
- 新增：过零检测 ±8 码滞回（波形稳定）
- 新增：频谱双门限底噪裁剪 + 对数刻度（频谱干净）

- 修复：Upp 2 倍偏差（误用 FFT 单边补偿）
- 修复：RAM 溢出（删除 s_voltage，省 32KB）
- 改动：波形/频谱显示点数 200 → 255

### V1（分支 stm32f407-gsignal-measurement）
- 基线版本：AD9226 DMA 采集 + 8192 点 FFT + 串口屏显示
- Upp 用 max-min 直接计算
- 波形直接线性插值，无滤波
